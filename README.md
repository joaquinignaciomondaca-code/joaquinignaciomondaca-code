## Proyectos destacados

### Sistema de Información Financiera de Chile (SIF)

MVP que busca centralizar, normalizar y documentar datos relevantes de distintas industrias financieras provenientes de fuentes oficiales. Facilita la consulta de información, la creación de indicadores y el desarrollo de análisis comparativos.

**Trabajo realizado:**
- Diseño de procesos reproducibles de extracción, validación, transformación y actualización de datos.
- Integración de información pública proveniente de organismos como la CMF y el Banco Central de Chile.
- Estructuración de datos para consultas SQL directamente desde el navegador.
- Controles de calidad, trazabilidad de fuentes y documentación para facilitar la reutilización de la información.

**Tecnologías:** Python · SQL · DuckDB · Parquet · ETL · GitHub Actions · JavaScript

### Pronóstico jerárquico de demanda intermitente en retail

Memoria de título orientada a predecir la demanda de una empresa de retail de moda femenina. El proyecto compara modelos estadísticos, de series temporales y de machine learning, con validación fuera de muestra y análisis de desempeño en distintos niveles de agregación.

**Trabajo realizado:**
- Preparación y análisis de datos de demanda intermitente.
- Desarrollo y comparación de modelos predictivos y de ensamble.
- Validación fuera de muestra y evaluación mediante métricas de error.
- Comunicación de resultados y análisis de su utilidad para decisiones de inventario y planificación.

**Tecnologías:** Python · Pandas · Machine Learning · Series temporales · Modelamiento predictivo

[Ver repositorio](https://github.com/joaquinignaciomondaca-code/Pronostico-Jerarquico-de-Demanda-Intermitente-en-el-Retail-de-Moda-Femenina-main)
